### 🚀 Features
- Added buttons for saving and marking as unread on reader screen (#1284) by @spacecowboy in [#1284](https://github.com/spacecowboy/feeder/pull/1284) 
- Added seekable read-aloud playback and spoken-text following (#1283) by @JaredTweed in [#1283](https://github.com/spacecowboy/feeder/pull/1283) 
- Added dedicated zoomable article image viewer (#1291) by @pengusto in [#1291](https://github.com/spacecowboy/feeder/pull/1291) 
- Widget respects read filter, added mark all as read button to widget (#1317) by @ashwebcode in [#1317](https://github.com/spacecowboy/feeder/pull/1317) 
- Made switches more expressive with check icon (#1320) by @spacecowboy in [#1320](https://github.com/spacecowboy/feeder/pull/1320) 

### 🐛 Bug Fixes & Minor Changes
- Fixed odd scrolling while refreshing with compact styles  (#1288) by @jl0277 in [#1288](https://github.com/spacecowboy/feeder/pull/1288) 
- Request LAN permission for local feeds on Android 17 (#1281) by @mvanhorn in [#1281](https://github.com/spacecowboy/feeder/pull/1281) 
- Fixed mixed RSS feeds preferring description over content (#1293) by @spacecowboy in [#1293](https://github.com/spacecowboy/feeder/pull/1293) 
- Restored Chinese local Bergamot translation (#1295) by @mvanhorn in [#1295](https://github.com/spacecowboy/feeder/pull/1295) 
- Improved feed refresh concurrency and reduced redundant storage work (#1280) by @JaredTweed in [#1280](https://github.com/spacecowboy/feeder/pull/1280) 
- Retained images from nested gallery figures (#1306) by @Doomguy-BFG9000 in [#1306](https://github.com/spacecowboy/feeder/pull/1306) 
- Defaulted scheme-less feed URLs to HTTPS (#1307) by @Doomguy-BFG9000 in [#1307](https://github.com/spacecowboy/feeder/pull/1307) 
- Corrected 1 pixel offset in nav drawer for some densities (#1323) by @spacecowboy in [#1323](https://github.com/spacecowboy/feeder/pull/1323)
